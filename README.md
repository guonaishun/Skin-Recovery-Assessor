# Skin Recovery Assessor

皮肤术前/术后图像恢复程度多维评价演示系统。用户可以在交互界面中选择“人脸分析”或“动物皮肤分析”，再分别选择术前照片、术后照片并点击“开始进行分析”。系统会自动完成图像配准、分析区域分割、红斑/肿胀/渗出结痂/干燥脱屑/色素肤质/针孔闭合等指标分析，并输出综合恢复评分、维度雷达图和过程可视化。

> 说明：本项目是比赛演示级工程原型，采用可解释传统计算机视觉指标。实际医疗使用前需要经过标注数据训练、临床验证和合规审查，不能直接作为诊断依据。

## 界面操作

1. 在左侧“分析对象”中选择：
   - 人脸分析：优先做人脸区域定位，并结合肤色 ROI 进行分析。
   - 动物皮肤分析：使用更宽松的表面/纹理 ROI，适合宠物、实验动物或动物局部皮肤照片。
2. 点击“选择术前照片”。
3. 点击“选择术后照片”。
4. 点击“开始进行分析”。
5. 右侧会实时播放分析过程，并展示综合评分、雷达图和各维度数据。

## 技术方案

1. 图像输入与标准化
   - 通过 Pillow 读取常见格式，包括 jpg、jpeg、png、bmp、tif、tiff、webp。
   - 自动修正 EXIF 方向，统一转换为 RGB，并缩放到可分析尺寸。

2. 术前/术后配准
   - 使用 ORB 特征点匹配和 RANSAC 单应性矩阵，将术后图对齐到术前视角。
   - 特征不足时回退为中心缩放对齐，保证流程稳定。

3. 皮肤区域分割
   - 人脸分析：结合人脸检测、YCrCb 与 HSV 肤色范围初筛。
   - 动物皮肤分析：结合颜色、亮度、局部纹理与最大连通区域提取目标表面。
   - 通过形态学闭运算、开运算、最大连通区域保留，得到更干净的分析 ROI。

4. 多维度评价
   - 针孔闭合度：检测治疗区小型暗圆斑/孔洞密度，比较术前术后数量与面积变化。
   - 红斑程度：Lab a 通道与 RGB 红度指数构建红斑热力图。
   - 肿胀程度：以局部平滑膨隆、亮度梯度下降、低纹理区域扩张作为 2D 图像代理指标。
   - 渗出与结痂：检测黄色高亮渗出、棕褐暗色结痂区域。
   - 干燥脱屑：检测高亮低饱和鳞屑、局部高频纹理。
   - 色素与肤质：检测暗沉/色素不均、亮度方差、边缘纹理均匀性变化。

5. 评分与可视化
   - 每个维度输出 0-100 分，越高代表恢复越好。
   - 生成综合恢复评分、变化结论、维度雷达图、差异热力图。
   - UI 以动画方式逐步展示图像变换流水线，适合比赛答辩演示。

## 后续可升级方向

- 使用 SAM/YOLO/UNet 做精确皮肤和病灶分割。
- 建立医生标注数据集，用 LightGBM 或 CNN/ViT 回归临床评分。
- 加入白平衡/色卡校正，降低拍摄光照误差。
- 增加同一患者多时间点恢复曲线与 PDF 报告导出。
